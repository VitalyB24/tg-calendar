# tg-calendar

*[English version](README.md)*

Инлайн-пикеры даты и времени для Telegram-ботов: два самодостаточных файла, только
стандартная библиотека. Кладёте в бота `tg_calendar.py` (месячный календарь) и, если
нужен, `tg_timepick.py` (пикер часов/минут), даёте каждому префикс колбэков — и получаете
клавиатуры, у которых колонки не «пляшут», а ширина не прыгает при навигации. На
инлайн-клавиатурах Telegram именно это — самое трудное. По умолчанию клавиатуры говорят
по-английски; русский набор подписей идёт в комплекте, любой другой язык подаётся
словарём (параметр `locale=`).

Обкатан в боевых ботах; дисциплина сетки ниже — итог десятков итераций на экране
реального телефона.

## Зачем он нужен

Инлайн-кнопки Telegram не стилизуются — ни жирного, ни цвета, ни кегля — а ширину кнопок
Telegram делит пропорционально длине текста. Наивный календарь поэтому рисуется с
«пляшущими» колонками и меняет ширину при каждом переходе. Модуль кодирует обходы:

- **Клетки постоянной ширины.** Каждая клетка дня добита до двух «слотов» figure space
  `U+2007` — неразрывным пробелом шириной ровно в цифру, который Telegram не обрезает
  (обычные пробелы обрезаются). Пустые клетки — два figure space. Колонки стоят на месте.
- **Заголовок постоянной ширины.** Название месяца — отдельная строка во всю ширину,
  добитая figure space до `TITLE_WIDTH`: самая длинная строка (а с ней и вся клавиатура)
  одинакова для любого месяца.
- **«Сегодня», которое видно.** Текст кнопки не стилизуется, поэтому сегодняшний день
  выделяется внутри глифов: необязательный эмодзи-маркер плюс стиль цифр — Unicode-жирные,
  полноширинные или keycap-цифры.

## Возможности

- Сетка месяца с навигацией назад/вперёд; недели начинаются с понедельника.
- Необязательный нижний ряд быстрых дат — Вчера · 📅 Сегодня · Завтра — и необязательный
  ряд отмены.
- Локализованные подписи: английский по умолчанию, русский в комплекте (`locale="ru"`),
  любой другой язык — своим словарём с валидацией при создании. См. «Локализация».
- Выделение «сегодня»: 14 маркеров × 4 стиля цифр; в каждой локали есть каталоги
  `markers` и `digit_styles` (значение, подпись) для экрана настроек бота — значения не
  зависят от локали, поэтому сохранённый выбор пользователя переживает смену языка.
- `months_keyboard()` — пикер месяцев «год одним взглядом», 4 ряда × 3 месяца, как на
  бумажном календаре, с той же дисциплиной ширины — сетка тянется до края экрана.
- `pad_center()` — экспортированный хелпер паддинга для любой полноширинной кнопки-заголовка.
- Устойчивость к кривым колбэкам: подделанный или обрезанный колбэк с префиксом календаря
  вырождается в no-op, а не в исключение — исключение, проглоченное обработчиком, оставило
  бы «крутилку» на кнопке висеть навсегда.
- Без состояния: один экземпляр `Calendar` обслуживает сколько угодно чатов. «Сегодня»
  инжектируется (`today_fn`) — поведение тестируется на фиксированной дате.
- `tg_timepick.py` — модуль-сосед, пикер времени: сетка часов → сетка минут → `"HH:MM"`,
  та же дисциплина ширины, тот же noop-парсинг. См. ниже.

## Быстрый старт

```python
import tg_calendar

CAL = tg_calendar.Calendar(prefix="cal")          # свой префикс на каждое использование

# показать выбор даты (например, когда мастеру нужна дата):
send(chat, "Выбери дату:", reply_markup=CAL.keyboard(2026, 6))

# в обработчике колбэков, до вашей собственной маршрутизации:
res = CAL.parse(data)
if res:
    kind, value = res
    if kind == "noop":
        answer_cb(cb_id); return
    if kind == "nav":                              # value = (год, месяц)
        answer_cb(cb_id)
        edit(chat, msg_id, "Выбери дату:", reply_markup=CAL.keyboard(*value))
        return
    if kind in ("pick", "today", "yesterday", "tomorrow"):  # value = datetime.date
        answer_cb(cb_id)
        use_the_date(value)                         # <- ваш код
        return
    if kind == "cancel":
        answer_cb(cb_id, "Отменено"); cancel_wizard(); return
```

## API

- `Calendar(prefix="cal", *, title_width=46, footer_today=True, footer_cancel=True,
  today_fn=datetime.date.today, locale="en")` — у каждого использования свой `prefix`,
  чтобы колбэки (`<prefix>:nav|pick|yest|today|tom|cancel|noop`) не пересекались с
  другими кнопками.
- `Calendar.keyboard(year, month, *, marker="none", digits="bold")` → dict
  `{"inline_keyboard": ...}` для `reply_markup`. `marker` — из значений каталога
  `markers` локали; `digits` — `plain | bold | wide | keycap`.
- `Calendar.parse(data)` → `(kind, value)` для колбэков календаря, иначе `None`:

  | колбэк | результат |
  |---|---|
  | навигация | `("nav", (год, месяц))` — перерисовать `keyboard(год, месяц)` |
  | день или быстрая дата | `("pick" / "today" / "yesterday" / "tomorrow", datetime.date)` |
  | отмена | `("cancel", None)` |
  | всё прочее с нашим префиксом, включая кривое | `("noop", None)` |
  | чужой колбэк | `None` |

- `months_keyboard(cb_for_month, locale="en")` → пикер месяцев 4×3; `cb_for_month(m)`
  отдаёт callback data для месяца 1..12, дополнительные ряды (назад/отмена) добавляет
  хост.
- `pad_center(s, width=TITLE_WIDTH)`, `style_digits(day, style)`,
  `month_title(month, year, width=TITLE_WIDTH, locale="en")` и словарь `LOCALES` со всеми
  наборами подписей.

## Пикер времени: tg_timepick.py

Модуль-сосед — независимый, копируйте только если нужен:

```python
import tg_timepick

TP = tg_timepick.TimePick(prefix="tp", minute_step=5, locale="ru")

# когда мастеру нужно время:
send(chat, "⏰ Выбери время:", reply_markup=TP.keyboard_hours())

# в обработчике колбэков, до вашей собственной маршрутизации:
res = TP.parse(data)
if res:
    kind, val = res
    if kind == "noop":    answer_cb(cb_id)
    if kind == "hours":   edit(..., reply_markup=TP.keyboard_hours())
    if kind == "minutes": edit(..., reply_markup=TP.keyboard_minutes(val))
    if kind == "pick":    use_the_time(val)        # val = "HH:MM"
    if kind == "cancel":  cancel_wizard()
```

Поток: сетка часов (00–23, четыре ряда по шесть) → сетка минут (`minute_step`, по
умолчанию 5, два ряда по шесть) → `("pick", "HH:MM")`. В виде минут есть ряды «назад к
часам» и отмены; `keyboard_hours(title=...)` принимает свой заголовок. Каждая клетка —
две цифры, заголовок — полноширинная строка с добивкой figure space: та же дисциплина, что
у календаря, и тот же контракт парсинга — кривой payload вырождается в `("noop", None)`,
чужой префикс возвращает `None`. Ввод времени текстом остаётся параллельным путём хоста —
пикер лишь добавляет тапы.

## Локализация

Все подписи живут в словаре `LOCALES` каждого модуля. Локаль по умолчанию — английская;
`locale="ru"` включает русский набор из комплекта (модули извлечены из боевых
русскоязычных ботов, так что русские строки — полноценные данные, а не довесок):

```python
CAL = tg_calendar.Calendar(prefix="cal", locale="ru")
TP = tg_timepick.TimePick(prefix="tp", locale="ru")
```

Любой другой язык — словарь той же формы в `locale=`; он валидируется при создании,
поэтому опечатка или пропущенная подпись падают сразу, а не позже внутри обработчика
колбэков. *Значения* маркеров и стилей цифр одинаковы во всех локалях — переводятся
только подписи — поэтому сохранённый по значению выбор пользователя переживает смену
языка. Дисциплина ширины от языка не зависит; следите лишь, чтобы строка заголовка
оставалась самой длинной строкой клавиатуры.

## Требования

Python 3.10+. Зависимостей нет.

## Разработка

Перед каждым коммитом — пять ворот; CI гоняет те же на каждый push:

```bash
ruff check .
python check_language.py
python check_versions.py
python sync.py
pytest
```

- **Репозиторий целиком на английском** — код, комментарии, докстринги, сообщения
  коммитов, документация. Русские строковые литералы — данные продукта (подписи UI,
  фикстуры тестов); `check_language.py` охраняет ровно эту границу: проза обязана быть
  английской, данные нельзя молча «починить» на английские.
- **Диапазоны зависимостей ограничены с обеих сторон** (`requirements-dev.txt`): нижняя
  граница — то, на чём реально гоняли сюиту, верхняя не даёт новому мажору приехать
  непрочитанным. `check_versions.py` доказывает, что машина попадает в диапазоны;
  Dependabot предлагает обновления, CI отвечает прямо на pull request.
- **Окончания строк в git — LF** (`.gitattributes`), что бы ни предпочитала ОС локально.
- **Потребители синхронизируются ИЗ репозитория.** Репозиторий — единственный источник
  правды для модулей и их тестов (синхронизируются и те и другие, так что сюита
  потребителя всегда тестирует ровно ту копию, которую он запускает). Раздаваемые тесты
  не несут собственного бутстрапа `sys.path`: потребителю нужен `conftest.py`, кладущий
  каталог модулей в `sys.path`, — он лежит в собственном `tests/` потребителя.
  Потребители перечислены, по каталогу на строку, в
  `sync_targets.txt` (файл машинно-специфичный и намеренно не отслеживается);
  `python sync.py` сообщает о любой копии, разошедшейся с репозиторием,
  `python sync.py --apply` перезаписывает копии версией из репозитория. Никогда не
  правьте модуль внутри бота: правка делается здесь, прогоняются ворота, затем
  применяется синк.
- **Осторожно с литеральными figure space.** В `tests/test_tg_calendar.py` есть литеральные
  символы `U+2007` внутри строковых аргументов — на вид это обычные пробелы. Редакторы и
  инструменты могут молча нормализовать их в `0x20`; ассерты написаны так, что это ломает
  сюиту, а не проходит тихо — после правки файла прогоните `pytest`. В самом
  `tg_calendar.py` figure space строится как `chr(0x2007)` — так и оставляйте.
